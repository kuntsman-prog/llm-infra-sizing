Сайзинг LLM-инфраструктуры

Сколько GPU нужно под нагрузку, уложится ли задержка в цель и что дешевле на горизонте нескольких лет: своё оборудование, аренда в облаке или API провайдера. Расчёт идёт прямо в браузере при каждом изменении параметров.

Нагрузка

Пояснения к полям и таблице

Модель

Модель
Открытая модель и число её параметров. MoE (смесь экспертов): на каждый токен работает лишь часть сети, «активные» параметры, поэтому генерация быстрее, но память нужна под все веса.
Веса
Формат хранения весов. fp16 и bf16: 2 байта на параметр, эталон качества. fp8 и int8: 1 байт, потери качества обычно малы. int4: около 0,5 байта, память в 4 раза меньше, но качество нужно проверить на своих задачах.
KV-кэш
Рабочая память модели о контексте запроса: для каждого токена каждый слой хранит ключи и значения внимания. fp8 вдвое меньше fp16, значит на GPU помещается больше одновременных запросов.

Нагрузка

Пользователей и запросов в день
Сколько людей или систем обращаются к сервису и сколько запросов в среднем делает каждый за рабочий день.
Вызовов модели на запрос
Для простого чата 1. Агент или RAG с переформулировкой вопроса вызывает модель несколько раз на одну задачу пользователя.
Доля трафика в пиковый час
Какая часть дневных вызовов приходится на самый нагруженный час. 0.2 означает 20%; для рабочего дня типично 0.15–0.25. Число реплик считается по пику, а не по среднему.
Промпт и ответ, токенов
Средняя длина входа (инструкция, история диалога, найденные фрагменты документов) и ответа. Токен примерно равен 3–4 символам русского текста, точнее зависит от модели.
Рабочих дней в месяц
Нужно для месячного объёма вызовов, стоимости API и аренды облака только в рабочие часы.

Цели и экономика

До первого токена, с (TTFT)
Сколько пользователь ждёт, пока ответ начнёт появляться. Для чата обычно 1–2 с, для пакетной обработки можно десятки секунд.
На токен, мс (TPOT)
Скорость «печати» ответа. 50–60 мс на токен это 17–20 токенов в секунду, быстрее, чем человек читает.
Резервная реплика (N+1)
Одна копия модели сверх нужного, чтобы отказ сервера или обновление не снижали качество сервиса.
Облако круглосуточно
Если снять отметку, аренда считается только в рабочие часы: 12 часов в рабочий день. Расчёт предполагает почасовую оплату по требованию (on-demand), когда остановленные машины не оплачиваются. При резервировании на год или три цена часа ниже, но платить нужно и за простой.
Электричество
Цена киловатт-часа для своего оборудования. Учтены потребление сервера (в 1,6 раза больше TDP GPU) и PUE дата-центра 1,5.
API, $ за 1М токенов
Цена провайдера за миллион входных и выходных токенов для модели сопоставимого класса. При смене модели вручную цены не меняются: подставьте прайс провайдера для выбранного класса.

Инженерные допущения

PUE и сервер к TDP
Сколько энергии тратит ЦОД сверх оборудования (1,2–1,3 у современных, 1,6–1,8 у старых) и во сколько раз сервер потребляет больше своих GPU.
Ставка дисконтирования
Приводит будущие ежемесячные платежи к сегодняшним деньгам. Покупка оборудования оплачивается сразу и не дисконтируется, поэтому ставка выше нуля делает облако и API относительно дешевле. При нуле затраты номинальные; для бюджетного решения на 5 лет задайте ставку, принятую в компании.
Эффективность памяти и вычислений
Какую долю паспортной пропускной способности памяти (генерация) и вычислительной мощности (обработка промпта) реально достигает движок инференса. По умолчанию 60% и 40%, это консервативно.
Целевая загрузка реплик
Насколько загружены копии модели в пиковый час. 70% оставляет запас на всплески; при 90% очередь и время до первого токена растут резко.

Сводка

Пиковый поток
Вызовов модели в секунду в самый нагруженный час: пользователи × запросы × вызовы × доля пика ÷ 3600.
Веса модели
Сколько памяти GPU занимают сами веса при выбранном формате.
KV-кэш на запрос
Сколько памяти занимает контекст одного запроса (промпт + ответ). Вместе с весами определяет, сколько запросов помещается на GPU одновременно.

Таблица подбора

GPU
Модель ускорителя. «Стенд»: потребительская карта, только для пилотов. «Не подходит»: причина, по которой цели недостижимы даже на 8 картах.
TP (tensor parallel)
На сколько GPU делится одна копия модели. Нужен, когда модель не помещается на одну карту или одной карты не хватает по скорости.
Реплик
Сколько независимых копий модели обслуживают поток, включая резервную. Пик занимает не больше 70% их мощности.
GPU всего и серверов
GPU всего = TP × реплики. Серверов: по 8 GPU в сервере.
Батч
Сколько запросов одна реплика обрабатывает одновременно, не выходя за цель по скорости. «Малый батч»: карта едва справляется и используется неэффективно.
TTFT, с
Расчётное время до первого токена в пиковый час, включая ожидание в очереди.
мс/токен
Расчётная скорость генерации при полном батче.
Своё, N лет
Покупка GPU и серверов, электроэнергия и обслуживание (по умолчанию 10% от стоимости оборудования в год). Без зарплат эксплуатации, лицензий и налогов. При ставке дисконтирования выше нуля будущие платежи приведены к сегодняшним деньгам.
Облако, N лет
Аренда того же числа GPU у облачного провайдера.
$ / 1М токенов, своё
Полная стоимость своего варианта, делённая на все токены (вход и выход) за горизонт. Её можно сравнить с ценой API за миллион токенов.

Как считается. Генерация ограничена пропускной способностью памяти: на каждом шаге GPU читает веса и KV-кэш всех запросов батча. Обработка промпта ограничена вычислениями, около 2 × активные параметры FLOP на токен. Батч подбирается максимальным, при котором время на токен укладывается в цель и KV-кэш помещается в память. Реплик столько, чтобы пиковый поток занимал не больше целевой загрузки (по умолчанию 70%) их мощности, плюс резервная при N+1.

Упрощения модели. Время до первого токена считается по обработке промпта одного запроса с учётом очереди; чередование обработки промптов и генерации в движке (chunked prefill) не моделируется. Загрузка реплики обработкой промптов берётся по верхней границе (целевая загрузка от предельной мощности), а реальный поток на реплику после округления и резерва меньше, поэтому время до первого токена оценено с запасом. Для MoE-моделей каждый токен проходит только через своих экспертов, поэтому объём вычислений считается по активным параметрам; при этом обработка промпта не может быть быстрее, чем один раз прочитать все веса из памяти, и эта граница учтена. Потери эффективности MoE-ядер покрываются консервативной эффективностью вычислений.

Точность ±30–50%. Это оценка порядка величины для выбора варианта и бюджета. Перед закупкой нужен нагрузочный тест на vLLM с реальными промптами. Своё оборудование не включает зарплаты эксплуатации, лицензии, налоги и хранилище (веса моделей, журналы, документы для RAG), а облако не включает хранение данных и сетевой трафик. RTX 4090 подходит только для стендов: лицензия драйвера GeForce не разрешает размещение в ЦОД.
